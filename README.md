# ✦ InfluenceOps (인플루언스옵스)
> **브랜드 핏과 콘텐츠 결을 지키는 인플루언서 협찬 의사결정 지원 SaaS**  
> *"수작업으로 대조하던 수십 시간의 탐색과 비효율을 줄이고, 브랜드 DNA와 제품 비주얼에 부합하는 인플루언서를 정밀 진단·비교·선정합니다."*

---

## 🚀 비즈니스 임팩트 (Key Results)
* **후보 검수 시간 95% 단축**: 50명 후보자 전수 조사 시 기존 수시간 ➔ **1분 이내 완료**
* **분석 운영 원가 75% 이상 절감**: 단일 고비용 분석 대비 **스마트 매칭 검증 시스템(2단계 정밀 분석 파이프라인)**으로 운영 효율 극대화
* **협찬 매몰비용 방어**: 브랜드 가이드라인 사전 충돌 분석 및 엄격한 환각(Hallucination) 방어 로직(근거 부족 시 '확인되지 않음' 표기)으로 협찬 미스매치 차단
* **실무 협업 생산성 향상**: 최종 선정자 명단 엑셀 원클릭 내보내기, 캠페인별 상태·D-Day 관리, 컨셉 복제로 기획 시간 단축

## ✨ 핵심 기능 (Features)

### 1. 브랜드 DNA 상시 동기화
- 브랜드 자사몰 웹사이트 링크 입력 시 브랜드 페르소나, 핵심 소구점, 비주얼 무드를 자동 추출 및 영구 저장
- 이후 진행되는 모든 캠페인에서 일관된 평가 기준으로 자동 적용

### 2. 캠페인 통합 기획 & 제품 링크 연동
- **협찬 대상 제품 링크 연결**: 판매처 링크 하나만 입력하면 대표 썸네일 자동 추출 및 `[제품 보러가기]` 연동
- **주력 포맷 맞춤 설정**: `✨ 자유/혼합`, `📷 이미지 피드 협찬`, `🎬 릴스(숏폼) 협찬` 선택에 따른 맞춤형 원고료 산정
- **캠페인 관리 대시보드**: 3단계 상태 변경(`준비/분석`, `진행 중`, `종료`), D-Day 계산 및 기간 연기/연장 모달, 컨셉 복사(가이드라인 복제), 휴지통(30일 보관 및 복원) 지원

### 3. 유연한 후보 등록 (파일 업로드 & 스마트 직접 수기 입력)
- **2-Tab 등록 모드**: 대량 후보를 위한 `파일 업로드(.csv/.txt)` 및 1~2명 소수 후보 빠른 검토를 위한 `직접 입력(수기)` 지원
- **스마트 정제 & 칩 프리뷰**: 엔터·쉼표·공백 자동 분리, `@아이디` 및 프로필 URL 자동 추출, 중복 자동 필터링 및 퀵 테스트 버튼 제공
- **건너뛰기 지원**: 후보 목록이 아직 준비되지 않았더라도 캠페인만 먼저 생성하고 나중에 등록 가능

### 4. 후보 분석 대시보드 & 스마트 랭킹
- **우선순위 기반 자동 랭킹**: 협찬 가능 후보는 매칭률 높은 순 최상단 정렬, 비공개·협찬불가 후보는 최하단 자동 고정
- **협찬 대상 제품 요약 바(Context Bar)**: 제품 실물 패키지와 인플루언서 피드를 나란히 대조 검토 가능
- **독립된 의사결정 인터랙션**: 체크박스는 **일괄 승인/취소** 전용으로 동작하며, 1:1 비교는 개별 **`[⚖ 비교]`** 버튼으로 명확히 분리
- **첫 사용자 유도 팝업**: 비교하기 기능을 자연스럽게 안내하는 코칭 툴팁 제공

### 5. 인플루언서 상세 분석 및 1:1~1:3 다자 비교
- **콘텐츠 근거 시각화**: 최근 피드/릴스 3건의 썸네일과 감도 점수 제공
- **근거 기반 프로필**: 피부 타입, 가족/반려동물 노출, 소통 진정성 등 근거가 확인되지 않은 항목은 추측하지 않고 '확인되지 않음'으로 안전 표기
- **후보 좌우 비교 (Compare)**: 최대 3인까지 지표·콘텐츠를 좌우로 한눈에 비교하고 즉시 후보를 추가할 수 있는 다이얼로그 지원
- **최종 선정자 엑셀 내보내기**: 승인 완료(`APPROVED`)된 인플루언서 명단을 정갈한 `.xlsx` 파일로 즉시 다운로드

## 🛠️ 시스템 아키텍처 (Tech Stack)

### Architecture Flow
```
[사용자 입력] 
  ├─ 자사몰 URL ──────> 브랜드 DNA 자동 추출 & DB 영구 저장
  ├─ 제품 링크 ───────> OpenGraph 썸네일(og:image) 자동 스크래핑
  └─ 후보 50명 등록 ──> [스마트 매칭 검증 시스템]
                          ├─ 1단계: 비공개·어뷰징 봇 사전 선별 (비용 절감)
                          ├─ 전처리: 릴스/이미지 비율 기반 주력 포맷 자동 감지
                          └─ 2단계: 브랜드 DNA 매칭 & 환각 방어 & 원고료 산정
                                      │
                                      ▼
                        [의사결정 대시보드 & 엑셀 추출]
```

* **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Axios
* **Backend**: FastAPI, SQLAlchemy, PostgreSQL / SQLite Fallback, Pydantic v2, BeautifulSoup4, HTTPX
* **AI Engine**: Google Gemini (1차 고속 선별) ➔ OpenAI GPT-4o (2차 정밀 분석), 비동기 병렬 처리

## 💻 로컬 실행 방법 (Getting Started)

### 1. 환경 변수 설정
프로젝트 루트 디렉토리에 `.env` 파일을 생성하고 아래 키를 설정합니다:
```env
OPENAI_API_KEY=your_openai_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
# 또는 OPENROUTER_API_KEY=your_openrouter_api_key_here
```

### 2. Backend 실행
```bash
cd backend
python -m venv .venv
source .venv/Scripts/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8001 --reload
```
* 백엔드 API 서버: `http://127.0.0.1:8001`
* Swagger API 문서: `http://127.0.0.1:8001/docs`

### 3. Frontend 실행
```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```
* 웹 서비스 접속: `http://127.0.0.1:5173`
